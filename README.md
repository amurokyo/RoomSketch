# RoomSketch 2.0.1

> 纯离线 · 单文件 · 户型绘图工具
> 户型绘制 / 家具图库 / Three.js 3D 预览 / PDF 多页导入 / 移动端适配 / 深浅双主题

一个**单 HTML 文件**的户型平面图绘制工具。无需安装、无需联网、无任何外部 CDN —— 把 `RoomSketch-2.0.1.html` 存到本地双击打开即可使用，也可以直接扔进 U 盘或内网共享给同事。

## ✨ 功能特性

### 绘制
- **墙体 / 折线**：连续单击添加拐点，默认自动横竖对齐网格（正交锁定），按住 Shift 可画斜线
- **门窗自动贴墙**：绘制门 / 窗松手后自动吸附最近墙段，并对齐墙体角度（水平 / 垂直 / 斜墙通吃）；贴墙后门窗与墙体建立关联，墙体移动 / 改形时门窗跟随，删墙后门窗转为待关联状态（琥珀色虚线框），可拖回墙边或一键重新吸附；3D 预览中门窗在墙体上形成真实开口（门洞过梁、窗台 + 玻璃 + 过梁）
- **多边形房间**：自动计算面积并在房间中心标注
- **尺寸标注 / 辅助线 / 文字标注 / 比例校准**（按已知长度两点校准全图比例）
- **PDF 图纸导入**：多页 PDF 逐页选择导入、矢量线条提取（Form XObject 内容内联、贝塞尔按规范展平）、无矢量页转图片底图、按颜色清理标注文字、框选区域删除
- **导出**：SVG 矢量 / PNG 位图（最高 6400px）/ 矢量 PDF（A4/A3，按 1:20~1:200 比例真实出图，超纸张自动放宽并提示）

### 家具
- 39 件预置家具图库（卧室 / 客厅 / 餐厨 / 卫浴 / 办公 / 通用，6 类），按关键字搜索
- 家具按类型绘制风格化图形：床有枕头被子、沙发有扶手坐垫、衣柜有门板挂杆……
- **圆形 / 椭圆家具体系**：圆床、圆形茶几、圆凳、圆形浴缸、立柱洗手盆、圆形会议桌、圆形地毯、圆形花坛
- 每件家具可设置**高度**（mm），名称关键字自动匹配形状

### 3D 预览（Three.js / WebGL）
- 一键生成整体等轴测视图：墙体按厚度与高度拉伸、门窗在墙上切出真实开口（门洞留空 + 2100mm 过梁，窗洞 900mm 窗台 + 1300mm 玻璃 + 过梁）、房间铺地板、家具按形状生成体块（方形棱柱 / 圆柱）
- 拖拽旋转 · 滚轮缩放 · 重置视角 · Esc 关闭；无可渲染对象时显示提示不建空白层，WebGL 不可用时降级显示几何统计与开口校验警告，二维编辑不受影响
- 顶栏列出未在 3D 中显示的对象类型及数量（如文字、尺寸标注）

### 效率操作
- 空白处拖拽 **框选多选**，整体移动 / 批量删除
- **方向键微移**（Shift 大步走）· **R 旋转 90°** · **Ctrl+C / Ctrl+V / Ctrl+D** 复制粘贴与副本
- 撤销 / 重做（80 步）、自动本地备份与恢复（恢复前须确认，缓存备份不是正式工程文件）
- 门扇开向、墙体厚度 / 高度、家具尺寸与高度全部可调

### 界面
- **深色 / 浅色双主题**，右上角一键切换，偏好本地记忆
- 桌面端三栏工作台；**移动端自动适配**（文件操作收进抽屉 + 底部快捷工具条 + 双指缩放平移）
- 全部动效尊重 `prefers-reduced-motion`

## 🚀 使用

```bash
# 无需构建，任选其一：
# 1. 直接双击打开 RoomSketch-2.0.1.html
# 2. 或本地起个静态服务
python3 -m http.server 8080
```

数据**仅保存在本机浏览器**（自动备份），支持导出为 JSON 工程文件在设备间流转。

## 📦 版本

- **v2.0.1** · 2026-11-15 · 划线预览冻结修复（见 CHANGELOG）
- **v2.0.0** · 2026-11-15 · Vue 3 + PDF.js + Three.js 重构版（见 CHANGELOG）
- **v1.0.0** · 2026-11-15 · 首个正式公开发行版本（零依赖单文件，Canvas 2D 轴测）

应用版本（`2.0.1`）与工程文件格式版本（`schemaVersion: 1`）分离：工程文件见 `format: "roomsketch"`。旧版 `{app: "RoomSketch", version: 2}` 工程与 1.0.0 工程均可打开，保存时自动升级为 2.0.1 格式；不支持的 `schemaVersion` 会明确报错，不再静默忽略。1.0.0 的自动备份（同 localStorage key）也可在 2.0.1 启动时确认恢复。

## 🛠 技术特点

- 单 HTML 文件，约 2.5MB（Vue 3.5.22 + pdfjs-dist 4.10.38 + three 0.182.0 全部内联），零 CDN、零运行时网络请求
- SVG 绘图画布 + Three.js WebGL 三维渲染（WebGL 不可用时降级提示）
- 源码见 `src/`（Vue 3 + TypeScript + Vite 6），构建：`npm run build`；测试：`npm test`
