# RoomSketch 1.0.0

> 纯离线 · 单文件 · 户型绘图工具
> 户型绘制 / 家具图库 / 3D 预览 / 移动端适配 / 深浅双主题

一个**零依赖、单 HTML 文件**的户型平面图绘制工具。无需安装、无需联网、无任何外部 CDN —— 把 `index.html` 存到本地双击打开即可使用，也可以直接扔进 U 盘或内网共享给同事。

## ✨ 功能特性

### 绘制
- **墙体 / 折线**：连续单击添加拐点，默认自动横竖对齐网格（正交锁定），按住 Shift 可画斜线
- **门窗自动贴墙**：绘制门 / 窗松手后自动吸附最近墙段，并对齐墙体角度（水平 / 垂直 / 斜墙通吃）
- **多边形房间**：自动计算面积并在房间中心标注
- **尺寸标注 / 辅助线 / 文字标注 / 比例校准**（按已知长度两点校准全图比例）
- **PDF 图纸导入**：矢量 PDF 线条提取、按颜色清理标注文字、框选区域删除
- **导出**：SVG 矢量 / PNG 位图（最高 6400px）/ 矢量 PDF（A4/A3，按 1:20~1:200 比例真实出图）

### 家具
- 40+ 预置家具图库（卧室 / 客厅 / 餐厨 / 卫浴 / 办公 / 通用），按关键字搜索
- 家具按类型绘制风格化图形：床有枕头被子、沙发有扶手坐垫、衣柜有门板挂杆……
- **圆形 / 椭圆家具体系**：圆床、圆形茶几、圆凳、圆形浴缸、立柱洗手盆、圆形会议桌、圆形地毯、圆形花坛
- 每件家具可设置**高度**（mm），名称关键字自动匹配形状

### 3D 预览
- 一键生成整体轴测视图：墙体按厚度与高度拉伸、房间铺地板并标注面积、家具按形状生成体块（方形棱柱 / 圆柱）
- 拖拽旋转 · 滚轮缩放 · 重置视角 · Esc 关闭，纯 Canvas 2D 画家算法实现，零依赖

### 效率操作
- 空白处拖拽 **框选多选**，整体移动 / 批量删除
- **方向键微移**（Shift 大步走）· **R 旋转 90°** · **Ctrl+C / Ctrl+V / Ctrl+D** 复制粘贴与副本
- 撤销 / 重做（80 步）、自动本地备份与恢复
- 门扇开向、墙体厚度 / 高度、家具尺寸与高度全部可调

### 界面
- **深色 / 浅色双主题**，右上角一键切换，偏好本地记忆
- 桌面端三栏工作台；**移动端自动适配**（文件操作收进抽屉 + 底部快捷工具条 + 双指缩放平移）
- 全部动效尊重 `prefers-reduced-motion`

## 🚀 使用

```bash
# 无需构建，任选其一：
# 1. 直接双击打开 index.html
# 2. 或本地起个静态服务
python3 -m http.server 8080
```

数据**仅保存在本机浏览器**（自动备份），支持导出为 JSON 工程文件在设备间流转。

## 📦 版本

- **v1.0.0** · 2026-11-15 · 首个正式公开发行版本

> RoomSketch 1.0.0 为项目首个正式公开发行版本。此前所有版本均为内部开发和测试版本，不构成正式发行版本。

应用版本（`1.0.0`）与工程文件格式版本（`schemaVersion: 1`）分离：工程文件见 `format: "roomsketch"`，旧版 `{app: "RoomSketch", version: 2}` 工程仍可打开，保存时自动升级为 1.0.0 格式。

## 🛠 技术特点

- 单 HTML 文件，约 130KB，零框架、零依赖、零构建
- SVG 绘图画布 + Canvas 2D 3D 轴测渲染器（画家算法）
- 纯原生 JS（ES6+），全部逻辑本地运行，**不发起任何网络请求**
